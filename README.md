# MOBA Browser JS

Легковесный браузерный прототип MOBA-игры (Multiplayer Online Battle Arena), написанный полностью на чистом JavaScript, HTML5 и CSS3. Сторонние игровые движки и библиотеки не использовались. 

Проект создан для практики модульной архитектуры игр, логики ИИ и рендеринга прямо в браузере.

## 🚀 Особенности
*   **Модульная архитектура:** Код разделен на логические модули (`ai.js`, `combat.js`, `abilities.js`, `render.js` и др.) для удобства поддержки.
*   **ИИ врагов:** Базовый искусственный интеллект, который перемещается по карте и вступает в бой.
*   **Система способностей:** Способности в стиле MOBA, привязанные к клавишам Q, W, E, R, с перезарядкой.
*   **Игровой цикл и волны:** Периодическое появление волн врагов.
*   **Мини-карта и камера:** Функциональная мини-карта для отслеживания объектов и камера, следящая за игроком.

## 🎮 Как играть
1. Скачайте или склонируйте этот репозиторий.
2. Откройте файл `index.html` в любом современном браузере.
3. Управляйте персонажем мышью, а способности активируйте клавишами **Q, W, E, R**.

## 🛠️ Стек технологий
*   **Язык:** JavaScript (ES6+)
*   **Разметка:** HTML5 / SVG
*   **Стили:** CSS3
